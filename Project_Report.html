ABSTRACT

The Project Management System (PMS) is a robust, desktop enterprise software application developed to automate, structure, and streamline the lifecycle management of software engineering projects, deliverables, team allocations, and developer productivity within an organization. Traditional project tracking often relies on disconnected spreadsheets, manual task logs, and informal messaging, which are prone to data inconsistencies, lack operational hierarchy, and lead to poor accountability. This project addresses these industry challenges by delivering a secure, centralized, and reactive desktop application that guarantees absolute transactional integrity, real-time analytics, and auditable governance.

The application is engineered strictly using the Java programming language and core Object-Oriented Programming (OOP) principles in full compliance with the APJ Abdul Kalam Technological University (KTU) PBCST304 syllabus. Core OOP principles including data encapsulation, inheritance, abstract classes, interface contracts, and dynamic method dispatch are rigorously leveraged. A multi-tier Model-View-Controller (MVC) architecture is implemented with Java Swing serving as the rich graphical user interface, coupled with an embedded SQLite database through JDBC for persistent data storage.

The system enforces strict Role-Based Access Control (RBAC) across three hierarchical tiers: Super Administrator (root organizational governance and administrator management), Project Manager / Admin (full project lifecycle planning, budget tracking, and team delegation), and Software Developer / User (task status transitions, execution, and work hours logging). Key functional highlights include recursive completion rollups across hierarchical Work Breakdown Structures (WBS), an interactive synchronized JTree component, automated session time-in tracking, and real-time audit logging.

Overall, the Project Management System demonstrates the practical application of object-oriented design patterns (Singleton, Adapter), custom exception handling, thread-safe database operations, and responsive GUI engineering, bridging academic curricula with production-grade software development standards.

INTRODUCTION

Modern enterprise software development requires rigorous tracking of milestones, deliverables, personnel allocations, and task hierarchies. As software teams scale in complexity, managing client commitments, budget ceilings, and cross-functional team responsibilities becomes critical to organizational success. Traditional project coordination often relies on manual logs, fragmented spreadsheets, or disjointed communication channels that lack automated validation, resulting in delayed deadlines, budget overruns, and opaque employee work logs.

The Project Management System (PMS) is developed to solve these fundamental engineering challenges by delivering an integrated, high-performance desktop platform that centralizes organizational project planning. Built using Java Swing and SQLite JDBC, the system provides an intuitive, responsive graphical workspace that allows project managers and software developers to collaborate efficiently while adhering to strict governance policies.

Object-Oriented Programming concepts form the foundational architectural pillars of the system. The application enforces a strict separation of concerns through an enterprise multi-tier architecture, dividing responsibilities cleanly into Domain Models, Service Contracts, Data Access Objects (DAO), and Event-Driven UI Adapters. Dynamic method dispatch is showcased through polymorphic user roles where access control checks and role descriptions are resolved dynamically at runtime.

Furthermore, the system demonstrates algorithmic sophistication through recursive Work Breakdown Structure (WBS) calculations. Task hierarchies of arbitrary depth are supported, where parent milestone completion percentages are recursively computed from constituent sub-tasks. By pairing recursive algorithms with custom JTable models via the Adapter design pattern and a thread-safe Singleton database manager, the system bridges classroom OOP theory with industry-ready software engineering practices.

UML CLASS DIAGRAM

The UML Class Diagrams illustrate the structural design and static relationships among entities, services, persistence layers, and Swing graphical user interface components in the Project Management System. The architecture strictly adheres to the Model-View-Controller (MVC) paradigm and SOLID engineering principles.

Core Model and Inheritance Hierarchy

The abstract BaseEntity class establishes common entity traits, implementing the Identifiable and Auditable interfaces. The abstract User class extends BaseEntity, providing common credential attributes while defining abstract polymorphic methods (hasPermission(Permission) and getRoleDescription()). Subclasses SuperAdmin, Manager, and Developer inherit from User and provide concrete implementations demonstrating Dynamic Method Dispatch. Entities Project, Task, and Team encapsulate commercial and technical domain data.

Service Layer & Persistence Layer

ProjectService and TaskService define high-level business contracts for project rollups and task state machine enforcement. DatabaseManager implements the thread-safe Singleton Pattern, managing SQLite database connections, schema initialization, and transactional CRUD methods.

Swing GUI Architecture & Adapter Pattern

MainFrame serves as the primary desktop application window, coordinating sub-panels (Dashboard, Projects, Tasks, Teams, Time Logs). To decouple domain collections from JTable rendering, ProjectTableModelAdapter and TaskTableModelAdapter implement the Adapter Design Pattern, extending Swing's AbstractTableModel.

Application Entry Points & Execution

When executed, the main(String[] args) method configures the native system Look & Feel, initializes the thread-safe DatabaseManager singleton, creates the SQLite schema tables if not present, synchronizes existing records, and launches the interactive modal LoginDialog on the Swing Event Dispatch Thread (EDT) via SwingUtilities.invokeLater().

Source Architecture & Layer Breakdown
  • Module 1 (Fundamentals & Logging): AppLogger utility leveraging varargs (Object... args), string formatting, and wrapper conversions.

CONCLUSION

The Project Management System (PMS) successfully demonstrates the practical, industry-aligned application of Object-Oriented Programming (OOP) concepts using the Java programming language. By combining Java Swing for an interactive, responsive desktop user interface with an embedded SQLite database through JDBC, the system provides a production-grade, self-contained solution for managing complex engineering projects, deliverables, and workforce resources.

The application drastically eliminates operational bottlenecks associated with manual spreadsheets by automating project scheduling, financial budget tracking, milestone decomposition, and developer attendance auditing. Granular Role-Based Access Control (RBAC) guarantees organizational security, ensuring that Super Administrators retain root governance, Project Managers direct project execution and team squad allocations, and Software Developers execute work items without unauthorized administrative access.

Every core topic outlined in the KTU PBCST304 Object-Oriented Programming syllabus has been rigorously implemented: from fundamental wrapper classes, control structures, and varargs loggers (Module 1); to deep inheritance hierarchies, constructor chaining, recursion, and dynamic method dispatch (Module 2); through custom exception hierarchies, SOLID principles, the Singleton pattern, and the Adapter pattern (Module 3); culminating in an event-driven Swing user interface and transactional JDBC persistence (Module 4).

The modular architecture ensures that the system is easily maintainable and extensible. Future enhancements may incorporate networked multi-client synchronization, Gantt chart scheduling visualizations, and automated email notifications. Overall, this microproject bridges the gap between academic object-oriented theory and commercial software engineering practice, delivering a robust, secure, and production-ready enterprise application.
